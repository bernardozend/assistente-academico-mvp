O protótipo foi desenvolvido em Python e utiliza uma arquitetura RAG.

Primeiro, os documentos acadêmicos simulados são processados, divididos em trechos e convertidos em representações vetoriais chamadas embeddings.

Esses vetores são armazenados no ChromaDB. Quando o usuário faz uma pergunta, ela também é representada semanticamente e o sistema recupera os trechos mais relacionados.

Esses trechos são então fornecidos como contexto para um modelo de linguagem Llama 3.2, executado localmente através do Ollama. O modelo gera a resposta condicionado por esse contexto, enquanto a aplicação apresenta também fonte e evidência. Antes desse processo há ainda uma camada experimental de privacidade para determinadas entradas sensíveis. A interface foi construída com Streamlit.


Utilizei modelos previamente treinados. O que desenvolvi foi a arquitetura de recuperação, integração, controle de contexto, interface e avaliação. RAG permite incorporar conhecimento documental no momento da consulta sem realizar treinamento do LLM com esses documentos.

“O RAG busca a informação, os embeddings ajudam a encontrar pelo significado, e o Llama gera a resposta. O Ollama roda o modelo localmente e o Streamlit mostra a interface.”

RAG = BUSCA
Embedding = SIGNIFICADO
LLM/Llama = RESPONDE
Ollama = RODA
Streamlit = MOSTRA
